# DSH File Viewer 演示文档

这是一个用来自测 **DSH File Viewer** 的 Markdown 示例文件。你可以在预览 / 源码两种模式间切换，所有代码块都会有语法高亮。

## 支持的渲染器

| 类型 | 渲染器 | 大文件策略 |
| --- | --- | --- |
| 图片 | Image | 整文件（≤50MB） |
| PDF | PDF.js | 整文件（≤100MB） |
| CSV | 数据表 | 分块 + 窗口化 |
| 文本 / 日志 | Text | 分块导航 |
| 源码 | Code | 分块 + 高亮 |
| Markdown | 预览 / 源码 | 头块读取 |
| JSON / YAML | 树 + 源码 | 整文件（≤8MB） |

## 功能清单

- [x] 自动选择 Renderer（MIME 优先，扩展名兜底）
- [x] 亮 / 暗主题跟随 Harness
- [x] 每个 Renderer 独立错误边界
- [x] 路径安全：只读工作区根目录内文件

> 引用块：预览永远不等于执行 —— Viewer 只读，绝不运行脚本。

### 代码示例

```python
def total(rows, column="销售额"):
    return sum(float(row[column]) for row in rows if row[column])
```

```typescript
export function openFile(path: string, options?: { line?: number; renderer?: string }) {
  viewerRegistry.resolve(file(path), options?.renderer)
}
```
