# 川西自驾游计划

> 8天7晚行程规划，含预算与路线。

## 行程总览

| 天数 | 路线 | 住宿 | 里程 |
|------|------|------|------|
| D1 | 成都 → 康定 | 康定 | 320km |
| D2 | 康定 → 新都桥 | 新都桥 | 180km |
| D3 | 新都桥 → 稻城 | 稻城 | 350km |
| D4 | 稻城亚丁徒步 | 香格里拉镇 | 0km |
| D5 | 稻城 → 理塘 | 理塘 | 240km |
| D6 | 理塘 → 丹巴 | 丹巴 | 400km |
| D7 | 丹巴 → 四姑娘山 | 日隆 | 120km |
| D8 | 四姑娘山 → 成都 | 成都 | 280km |

## 预算明细

- 油费过路费：约 ¥3,500
- 住宿：约 ¥4,800（平均 ¥600/晚）
- 餐饮：约 ¥2,400（¥300/天）
- 门票：约 ¥1,200
