# DeepSeek 文件查看器 使用说明

> 本文件用于测试 **Markdown 渲染器** 的完整能力。

## 特性清单

1. **图片预览** — PNG/JPG/GIF/WEBP/SVG
2. **PDF 阅读** — 页码导航、缩放
3. **CSV 表格** — 排序、搜索、列宽调整
4. **代码高亮** — 支持 20+ 语言

## 公式示例（内联）

当 `x = 2` 且 `y = 3` 时，`x² + y² = 13`。

## 引用

> 预览 ≠ 执行：查看器严格只读，不会运行任何脚本。

## 嵌套列表

- 文件类型
  - 文本类
    1. TXT / LOG
    2. INI / CONF
  - 富文本
    1. Markdown（消毒后渲染）
    2. HTML（仅源码）
- 数据类
  - CSV / TSV
  - JSON / YAML

## 代码块

```typescript
// 客户端 API 示例
const fileViewer = ctx.get('fileViewer')
await fileViewer.openFile('/workspace/output/report.csv', { line: 125 })
```
