# Product

## Register

product

## Users

DeepSeek Harness users inspecting workspace files and generated artifacts without leaving the current session. They need fast, read-only previews across common document, data, image, and source formats, including large and remote files.

## Product Purpose

DSH File Viewer adds a trustworthy, first-class preview surface to DeepSeek Harness. Success means a file opens in context, remains safe and responsive at any supported size, and feels native to the surrounding Harness interface.

## Brand Personality

Quiet, precise, dependable. The viewer should recede behind the content and inherit the host application's interaction vocabulary.

## Anti-references

Avoid a standalone file-manager aesthetic, decorative editor chrome, custom controls that conflict with Harness conventions, and any interaction that implies previewed content can execute or mutate files.

## Design Principles

- Match Harness before adding plugin-specific treatment.
- Keep file content primary and controls compact.
- Make read-only and safety boundaries unambiguous.
- Preserve responsiveness for large and remote files.
- Use familiar, accessible controls and predictable keyboard behavior.

## Accessibility & Inclusion

Maintain WCAG 2.1 AA contrast, visible keyboard focus, semantic labels, and usable controls across light and dark Harness themes. Respect reduced-motion preferences and do not rely on color alone to communicate state.
